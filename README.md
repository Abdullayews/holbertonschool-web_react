## 🧭 About this repository

The React track starts where modern front-ends actually start: **the type
system**. This repository is the TypeScript project — six self-contained
webpack mini-projects that climb from basic annotated interfaces to the
exotic corners of the language: ambient `.d.ts` declarations, namespace
merging, and branded nominal types.

Every task folder has its own `package.json`, `tsconfig.json`,
`webpack.config.js` and `js/main.ts` — plus a README explaining the
concept it drills.

## 📚 The project

| Project | What it covers |
|---|---|
| [`TypeScript/`](TypeScript/README.md) | The whole project — tasks 0–5 + the original study notes |

**The six tasks inside:**

| Task | Concept |
|---|---|
| `task_0` | Interfaces + typed DOM manipulation |
| `task_1` | Extended interfaces & constructor-typed classes |
| `task_2` | Literal types, type predicates, narrowing |
| `task_3` | Ambient declarations — typing an untyped library |
| `task_4` | Namespaces & declaration merging |
| `task_5` | Nominal typing via `_brand` fields |

## 🛠️ Environment

- Node.js + npm · TypeScript 5 · Webpack + Babel · ESLint
- Each task folder builds independently

## 🚀 Build a task

```bash
git clone https://github.com/Abdullayews/holbertonschool-web_react.git
cd holbertonschool-web_react/TypeScript/task_3
npm install && npm run build   # ambient declarations at work
```
